## Critical operating constraints (do not violate)

These come from prior incidents. Honoring them saves real time.

- **OneDrive sync lag in the sandbox.** The Linux sandbox mount of the workspace folder lags behind Windows. The `Read` / `Edit` / `Write` tools go to Windows directly (canonical); the `Bash` tool sees the lagging mount. Practical effect: `tsc --noEmit` from bash sometimes sees stale or truncated content, even though the file is fine on Windows. Symptoms: `TS1127 Invalid character` errors on impossible columns, or "Unexpected end of input" with the tail showing mid-statement truncation. Cure: re-read via Read tool to confirm Windows-side; trust Vercel/Render to be the source of truth for actual build correctness. **Do not** re-write the file from sandbox to "fix" sandbox-side truncation — you'll wipe what Windows already has.

- **No emojis unless he asks or uses them first.** He uses some in commit messages but not in conversations. Don't sprinkle.

- **Don't write README or .md docs unless asked.** Markdown handovers like this one are explicitly requested. Self-generated commentary docs are not wanted.

- **No `Other` options on `AskUserQuestion`** — the platform adds it automatically.

- **JWT in `?token=` is OK for downloads, NOT for writes.** The contract-app download flow uses `?token=` query auth because iframes can't carry headers. That dependency (`get_user_for_download` in `aq-backend/app/core/auth.py`) is scoped to read-only endpoints. Don't extend it to mutate endpoints — token-in-URL leaks through browser history and access logs.

- **Generated contract IDs stay INSIDE the PDF via the `{{ id }}` template field.** Don't move them back into filenames. The current filename pattern is `vendor - brand - DD-Mon-YYYY.{pdf,docx}`.

- **For non-ASCII (Arabic) filenames on contract downloads, use the native browser download via hidden iframe + `?token=`.** All JS-mediated paths (blob URL, data URL, showSaveFilePicker's suggestedName) silently strip non-ASCII on Chrome+Windows. The iframe approach is in `downloadFile` in `public/contracts/app.js`. Don't touch it without a strong reason — we went through five iterations to land here.

- **Render free tier — 512 MB RAM, sleeps after idle.** Batch PDF generation chunks at 4 contracts with `gc.collect()` between; LibreOffice runs with `--norestore --nologo --nofirststartwizard --nolockcheck` + a fresh `UserInstallation` profile per call. GitHub Actions cron in `aq-backend/.github/workflows/keep-warm.yml` pings `/api/health` every 14 minutes to fight cold starts.

- **Supabase keys.** Service-role key is now the **new opaque key format** (`sb_secret_...`), not the legacy JWT (`eyJ...`). The backend's `app/core/supabase.py` knows: legacy JWT keys go in both `apikey` and `Authorization: Bearer`; new opaque keys go ONLY in `apikey` — sending them in Authorization makes Postgrest 500 with "Expected 3 parts in JWT". The PM app's `SUPABASE_SERVICE_ROLE_KEY` (in Vercel env vars) is also the new format. **Do not** prefix it with `NEXT_PUBLIC_`; it must stay server-only.

## What landed in this session

In rough order. Every commit was pushed and (mostly) deployed.

### 1. Contract app: download flow stabilized (Arabic filenames)

Saga over five iterations ended with **native iframe download + `?token=` query auth**. The contract-app calls `downloadFile(path, fallbackName)` which:
- Runs a `HEAD` pre-check (with auth header) to detect missing files, triggering `/regenerate` if needed.
- Opens a hidden iframe at `${API_BASE}${path}?token=<jwt>`. Iframe-driven downloads bypass JS sanitization and respect the server's `Content-Disposition: filename*=UTF-8''<urlencoded>` header.

Backend support:
- `aq-backend/app/core/auth.py`: `get_user_for_download` dependency accepts JWT in `Authorization` header OR `?token=` query param.
- `aq-backend/app/routers/contracts.py`: download endpoints declared as `@router.api_route(..., methods=["GET","HEAD"])` so HEAD works (FastAPI doesn't auto-bind HEAD to GET).
- `aq-backend/app/main.py`: CORS `allow_methods` includes `HEAD`.
- `aq-backend/app/routers/contracts.py`: `_pretty_download_name` skips empty parts; `_content_disposition` emits both ASCII fallback + `filename*=UTF-8''`.

If a download is failing again, check in order: (a) is the backend deployed past commit `da43b44`, (b) is `?token=` actually in the iframe URL, (c) is `Authorization` bearer present on the HEAD pre-check.

### 2. Vendor categories (migration 029)

Eleven categories seeded in `public.vendor_categories`: influencer, ugc, props, makeup_artist, logistics, model, videographer, rentals, events, location, photographer. Each row has `requires_license` (true for influencer + ugc only). ## Conventions and gotchas

- **Vendor `bank_accounts` is 1-to-many.** Schema has always supported it; UI only just caught up. Never assume a vendor has at most one bank.
- **Slot names for files.** Per migration 032: `'license'`, `'id'`, `'bank:<id>'`, `'headshot'`, `'equipment'`, `'location_photos'`, `''` for legacy. Use `bankSlot(id)` helper rather than templating manually.
- **Storage paths inherit the slot.** Format: `{vendor_id}/{safe_slot}/{rand}-{safe_name}` (slot colons rewritten to underscores). Both apps produce identical paths so files look the same in Supabase Studio regardless of source.
- **Render free tier is fragile.** PDF batches > 4 contracts at once OOM. Chunking is in place; don't undo it.
- **OneDrive can delete `.git/objects/XX` files.** Defender exclusion: `Add-MpPreference -ExclusionPath "C:\Users\siraj\OneDrive - AQ Creativity\<repo>\.git"` from an Admin PowerShell. Siraj already has this set up but a fresh repo would need it.
- **The Supabase service-role key bypasses RLS.** Do not embed it in any client bundle. Routes that use it must validate the caller's permissions explicitly (see `/api/team/admin-create` for the pattern).
- **Cache busters on the contract app** look like `?v=20260611-design-c-modal`. Bump on every visible JS or CSS change. Otherwise Vercel's CDN serves stale and Siraj will see "the change didn't land."
